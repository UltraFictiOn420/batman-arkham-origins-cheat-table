# Origins Original v5 — real Anarky countdown hold

User reports v4 did not stop the timer even after a checkpoint reload. Live inspection after that reload identified a newly allocated second Anarky timer: start 160 seconds, remaining time about 133 seconds, flags 3 (running bit 2 and pause bit 1 both set). It continued decreasing to about 107 seconds with that flag state. Thus v4's target selection was not the remaining issue: Anarky's actual countdown ignores bPauseTimer. The prior temporary helper could conceal this because it directly rewrote the remaining time.

v5 replaces the Anarky pause-bit write with direct holding of RemainingTime (float +0x100) and IntRemainingTime (+0x104). It captures the remaining time when each active timer is bound and replenishes those two fields each runtime tick. It retains auto-follow for subsequent eligible bombs, same-object identity validation, live running/countdown checks, package/duration restrictions, exclusion of challenge timers, waiting between races and ambiguity guards. It does not write any timer or mission flag for Anarky. Off stops replenishment and resumes naturally from the held time; it does not rewind to pre-enable time.

Disable the old initializer, load v5, initialize, then enable **Hold Anarky Bomb Countdowns (auto-follow next bomb)**. Leave it enabled between bombs. All other cheats and hotkeys are unchanged.

A bounded helper temporarily holds the reloaded current timer at 107 seconds (1:47) for at most 180 seconds while v5 is delivered. The helper eventually exits automatically and must not be mistaken for proof that v5 runs correctly in CE. User should confirm standalone holding after the helper expires and normal mission progression/disarming. The 180-second third-bomb variant still needs live gameplay confirmation.

Internal tests: XML/Lua syntax and feature coverage; actual v5 Lua using live reads and simulated writes for precise field scope, float/integer refill despite an already-set pause bit, disable, transition to next timer, waiting/stop/ambiguity and non-Anarky exclusions. Tests do not perform live writes. Test source: work/test_origins_anarky_hold.py. v1–v4 CTs are preserved.

All listed simulated-write checks passed with the current real selected timer, held value 107 and flags 3. Before handoff, process inspection confirmed the temporary helper had already exited; subsequent user testing can therefore test v5 without that helper concealing results.
