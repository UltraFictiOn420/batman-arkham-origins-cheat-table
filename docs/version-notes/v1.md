# Batman Arkham Origins — Original v1

Status: initial testing build, not a final release.

Follow-up user confirmation October 8, 2026: Infinite Health and melee Super Damage seem to work in gameplay. v2 expands the feature set; v1 CT remains preserved.

## Scope

- Infinite Health: replenish the controlled player's positive health to HealthMax. Does not prevent instant/scripted death or knockback.
- Super Damage: cap live enemy health at one-tenth of its reflected MaxHealth (minimum 1). This is an effective damage boost, not a true outgoing-damage multiplier. Main keyboard minus toggles it. Boss-named classes excluded; scripted fights/tutorials are not guaranteed safe.
- No console unlocker, code injection, shared VM patch, armor edit, scan/input change, or auto-enabled cheat.
- Batarang-specific knockout logic and all other wishlist options deferred.

## Use

Load the CT in Cheat Engine after loading Steam single-player gameplay. Activate the required initializer, then Infinite Health. Super Damage is optional; leave it off for scripted/tutorial/boss/interrogation encounters. Initializing may briefly pause the CE interface while metadata is checked. No logging popup is used. Disable the initializer before switching tables; reinitialize after restarting the game.

Enemy HP already reduced is not restored on disable. Reloading/respawning is required to undo those HP reductions. Back up saves and avoid combining tables.
