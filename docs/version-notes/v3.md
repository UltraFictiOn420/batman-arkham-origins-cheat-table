# Origins Original v3 — Anarky countdown

Includes all v2 options plus Side Missions / Anarky Bombs / Freeze Current Anarky Bomb Countdown.

Disable the previous initializer before loading v3. Enable the new initializer, then the Anarky toggle during an active bomb race. Disable the toggle to resume. Once a bomb is complete, switch the toggle off and on during the next bomb's countdown to bind that timer.

The currently identified live countdown belongs to OpenWorld__ChA1234, starts at 230 seconds (3:50), and was the only running non-challenge HUD timer. Its remaining time matched the user-described event. Other loaded timers in this package start at 160 and 180 seconds; the selector permits those variants, but their Anarky gameplay association still requires testing.

The CT changes only the selected live timer's bPauseTimer bit (RSeqAct_HUDTimer +0x108, mask 1). It validates reflected fields, package, duration, running/countdown state and unique candidate count. It captures object identity; stops writing after the timer ends; restores the original pause bit on disable without altering other bits. It does not disarm bombs, complete objectives or change mission flags. Challenge timers and count-up timers are excluded. General gameplay timers remain untouched.

A separate bounded temporary helper held the live remaining-time float/integer at 126 seconds for at most 180 seconds during development, stopping early if the mission timer stops or object identity changes. It sets no pause or mission flags. This helper is not included in the CT and eventually releases automatically; enable the v3 toggle for the continuing hold. Internal Lua tests use live reads and simulated-write overlays; native pause behavior and mission completion need user confirmation.

v1/v2 tables remain available as fallbacks. Development additions: work/origins_anarky_rescue.py and work/test_origins_anarky.py. The current Lua and builder target v3.
