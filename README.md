# Batman Arkham Origins — Original Cheat Table

Private preservation archive of an original, user-led, AI-assisted single-player Steam Cheat Engine project.

**State: paused, with unfinished gameplay testing.** Latest retained build: v5. This is not a final verified release. User confirmed Infinite Health and melee Super Damage in v1. The final Anarky countdown fix has not yet received a standalone user test.

## Organized contents

- `tables/latest-test/v5/`: latest test table, unverified Anarky hold revision.
- `tables/history/v1..v4/`: byte-for-byte historical tables, including unsuccessful timer revisions.
- `docs/STATUS_AND_TESTING.md`: confirmed versus unconfirmed features.
- `docs/version-notes/`: original per-version notes.
- `catalog/versions.json`, `catalog/features.json`: machine-readable version/feature classification.
- `development/work/`: latest development source and historical research/test helpers.
- `CHECKSUMS.sha256`: artifact integrity checks.

Enable the required initializer in Cheat Engine, then individual toggles. No developer console setup is required. Read the safety document first. Never use in multiplayer/competitive/anti-cheat sessions. Third-party trainers, reference tables, game files, memory dumps, dependencies, credentials, and savegames are not included.

Historical CTs embed their historical Lua. The standalone external runtime/builder are latest v5 source, not separate preserved source files for every old version. No license has been selected by the owner.
